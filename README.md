One office joke, one line, under 200 characters — an entry for the
[make.fun bounty](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a).

## The joke

> I set my out-of-office reply to 'per my last email' so the thread can argue with itself while I'm away.

## How it works

`main.ts` writes the joke to `/output/entry.txt` (103 characters, single line),
falling back to an `output/` folder next to the script when `/output` is not
writable. Run it with `node main.ts`.
